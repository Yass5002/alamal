# Laboratoire AL AMAL

> The official website for Laboratoire AL AMAL

This repository contains the source code for the official website of Laboratoire AL AMAL, a premier medical analysis laboratory located in Meknes, Morocco. The website serves as a digital storefront providing critical information about medical services, opening hours, and contact details for patients.

## Project Overview

The website is designed to be fast, accessible, and fully responsive across all devices. It provides patients with easy access to the laboratory's services and allows them to request home sampling.

### Key Features

* **Multilingual Support** Fully translated into French, English, and Arabic to serve a diverse patient base.
* **Responsive Design** Optimized for both desktop and mobile viewing.
* **Service Catalog** Detailed information on available medical analyses including Hematology, Biochemistry, Immunology, and more.
* **SEO Optimized** Includes comprehensive meta tags, structured schema data, and dynamic sitemaps for maximum search engine visibility.
* **Interactive Elements** Features a dynamic testimonial carousel, FAQ accordion, and integrated Google Maps for easy navigation.

## Technical Stack

The project is built using modern, lightweight web technologies without heavy frameworks to ensure maximum performance and minimal load times.

* **HTML5** Semantic and accessible markup.
* **Vanilla CSS3** Custom styling with responsive media queries and modern layouts.
* **Vanilla JavaScript** Lightweight DOM manipulation for the mobile menu, language switcher, and interactive components.

## Getting Started

Since this is a static website, no complex build process or server setup is required.

1. Clone the repository to your local machine.
2. Open `index.html`, `en.html`, or `ar.html` directly in any modern web browser.
3. For development, you can use any local server extension like Live Server in VS Code to preview changes instantly.

## Repository Structure

* `index.html` The main French landing page.
* `en.html` The English localized page.
* `ar.html` The Arabic localized page with RTL support.
* `styles.css` The global stylesheet.
* `script.js` The interactive logic.
* `assets` Various web optimized images, logos, and favicons.
